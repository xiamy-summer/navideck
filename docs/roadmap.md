## 待办队列（按优先级，从高到低）

### P1 核心体验补全

1. **自定义背景图 / 主题预设**
   - 背景图：现只有 URL 输入，可加本地上传（复用 /api/upload）。
   - 主题预设：内置几套配色（如 蓝/紫/绿/暖橙），一键切换 accent + canvas 色；可加「随机」按钮。
   - 入口：设置中心 → 外观 → 基础组。

2. **搜索引擎管理增强**
   - 现状：搜索框默认引擎单选（设置里可管理引擎列表）。
   - 增强：搜索框点击引擎图标下拉切换、支持拖拽排序、Emoji 图标。
   - 入口：设置中心 → 搜索。

### P2 个性化与效率

3. **Emoji 图标页签**（小活）
   - IconPicker 加 Emoji 页签，与 Iconify / 本地上传并列，几分钟完成。

4. **分组共享 / 公共分组**（个人场景低优先级，多人用才需要）
   - 全局设置里把某些分组标记为「公共」，所有用户只读可见。

5. **操作审计日志**
   - 记录登录/修改/删除/导入导出等操作（users 能区分到人即可），设置中心 → 系统状态 加一页日志查看。个人场景价值中等。

### P3 安全与健壮性

6. **2FA（TOTP）**
   - 账号设置里启用两步验证（otplib 生成/校验，扫码绑定）。个人 + OIDC 场景优先级低。

7. **备份自动推送到外部存储**
   - 定时备份产物推送到 NFS/WebDAV/S3（群晖场景可配 Remote Sync）。可选。

### P4 平台与集成

8. **更多界面语言**
   - 现有 zh-CN / en-US；可加 繁中 / 日文（做 1 个约 468 行文案，半天）。

9. **移动端 App 化**
    - PWA 已可安装；若想更好体验可做「分享/添加到主屏」引导页（安装提示横幅，iOS 需要）。

10. **分组页（多页模式）**
    - 单页过长时提供分组页签模式（顶部 tab 切换分组集），可选开关。

## 技术备忘（做新功能前先看）

- 数据库懒加载 Proxy（better-sqlite3，防构建期 SQLITE_BUSY）。
- 版本号三处同步；推送用 `python3 scripts/sync-github.py <token> -m "feat: ..."`（Actions 标题取提交首行）。
- build 后必须复制 public 与 .next/static 到 standalone（脚本已内置）。
- OIDC 全局配置入口在趋势「全局设置」下拉，勿隐藏该入口。
- 图标上传链路：`POST /api/upload` → `GET /api/files/<hash>.<ext>` → Icon.tsx 渲染 img。
- 旧 `border-t border-line pt-5` 结构已全部替换为 Section 组件（SettingsPanel.tsx 内）。
